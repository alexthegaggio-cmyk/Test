Bottle

A whole Linux computer in one HTML file. Bottle is a from-scratch RISC-V RV32IMA + Zicsr emulator written in JavaScript. It boots an unmodified Linux 6.1.14 kernel (nommu, with a Buildroot userland) and the emdoom port of DOOM inside this page. The kernel images ship gzipped inside the file and are inflated in the browser; nothing is fetched.

Machine map

0x80000000RAM, 64 MiB · kernel image at +0, DTB near the top
0x10000000UART · write = console out · +5 LSR, polled
0x1100bff8CLINT mtime · 0x11004000 mtimecmp
0x11100000SYSCON · 0x5555 poweroff · 0x7777 reboot

Machine mode only; traps are direct; the timer is the only interrupt source. Compressed instructions are not implemented — the kernel is built without them.

Debugger

Pause the machine at any time. Registers flash when they change; the disassembly follows pc; click the gutter to set a breakpoint, or click a line and Run to cursor. The memory view is live and bytes are editable. The assembler builds a bare-metal program and runs it on the same core.

Credits

  • Machine model after mini-rv32ima by Charles Lohr (MIT/BSD) — the images boot unchanged on it.
  • Linux 6.1.14 rv32 nommu kernel with a Buildroot userland; DOOM is the emdoom port rendering to the terminal.
  • Terminal by xterm.js (MIT). Type set in JetBrains Mono and Inter Tight.

Login is root, no password. Everything runs in a Web Worker; the page never blocks.
